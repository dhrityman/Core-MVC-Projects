   To Create a new Product, do the following steps:
  17.
  Now we are going to create a new Product, so create a new product, create a new model class of Type DTO (Data Transfer Object) named as "ProductDTO" in the folder named "Models" in the project and add properties for each field that we want to include in the form. 
  Which allow to user to submit the product details to the server. This class will be used to transfer data between the view and the controller.
  Decorate the required properties with the [Required] attribute to ensure that the user provides values for those fields.
  To upload actual image file, we need to add a property of type IFormFile in the ProductDTO class. This property will be used to handle the uploaded image file from the form.

  18.
    Create a new action method named "Create" in the ProductsController class to handle the Create operation. 
    This action method will be responsible for displaying the form to create a new product and handling the form submission.

  19.
  Create new view named "Create.cshtml" in the Views/Products folder to display the form for creating a new product.
  Right click on ProductsController.Create() method, and add view, add Empty Razor view named as "Create.cshtml".
  After adding a Empty Razore view named Create.cshtml, you will see a new view file added with the name as Create.cshtml 
  under View=> Product folder. 
  
  STEP 19.1: Register the model class (ProductDTO) in the Create.cshtml view to bind the form fields to the properties of the ProductDTO class.
  We need it because we need to bind witht the form (Create.cshtml) fields to the properties of the ProductDTO class.

  STEP 19.2:Add the Form body of Create.cshtml.

  STEP 19.3: Add the form submission logic in the Create action method of the ProductsController class to handle the form submission and save the new product to the database.
        STEP 19.3.1: Create [HttpPost] method for 'Create' at ProductsController.
        STEP 19.3.2: Add validation logic to check if the model state is valid. If not, return the view with the validation errors.
        STEP 19.3.3: If the model state is valid, create a new Product entity and populate its properties with the values from the ProductDTO object.
        Step 19.3.4: First need to save the Product Image file to the server. To do this, we need to check if the IFormFile property of the ProductDTO object is not null and has a valid file name.
            *       If it does, we can generate a unique file name for the image file and save it to a specific folder on the server using the IFormFile.CopyTo() method.
            *       Save the new Product entity to the database using the ApplicationDBContext and call SaveChanges() to persist the changes.
            *       1. Add a parameter in the contructor of Type IwebHostEnvironment to the Create action method to get the path of the wwwroot folder.
            *       2. Create a unique name of file name of the Product Image file to avoid overwriting existing files with the same name.
            *       3. Get the full path of the Product Image file by combining the wwwroot folder path, the folder name where the images will be stored, and the unique file name.
            *       4. Create a new FileStream object with the full path and FileMode.Create to create a new file or overwrite an existing file with the same name.
            *       5. Use the IFormFile.CopyTo() method to copy the contents of the uploaded image file to the new file stream, which will save the file to the server.
            *       6. Create a new Product entity and populate its properties with the data from the ProductDTO object, including the unique file name of the uploaded image to save in database.
            *       7. Save the new Product entity to the database using the ApplicationDBContext and call SaveChanges() to persist the changes.

    STEP 19.3: After successfully creating the product, redirect the user to the Index action of the ProductsController to display the list of products.

 To Edit or update a existing Product, do the following steps:
 
 20.
 STEP 20.1: Create a new action method named "Edit" in the ProductsController class to handle the Edit operation. 
    This action method will be responsible for displaying the form to edit an existing product and handling the form submission.
  
  STEP 20.2: Create new view named "Edit.cshtml" in the Views/Products folder to display the form for editing an existing product.
  Right click on ProductsController.Edit() method, and add view, add Empty Razor view named as "Edit.cshtml".
  After adding a Empty Razore view named Edit.cshtml, you will see a new view file added with the name as Edit.cshtml 
  under View=> Product folder. 
  
  STEP 20.3: Register the model class (ProductDTO) in the Edit.cshtml view to bind the form fields to the properties of the ProductDTO class.
  We need it because we need to bind witht the form (Edit.cshtml) fields to the properties of the ProductDTO class.

  STEP 20.4:Need to add the following new fields in the Edit.cshtml view:
  Add new Field to display ID of the Product in the Edit.cshtml view. This field will be used to identify the product being edited and will be hidden from the user.
  Add new Field to display the existing image path of the Product in the Edit.cshtml view. This field will be used to show the current image of the product being edited and will be displayed as an image element in the form.
  Add new Field for CreatedAt property of the Product in the Edit.cshtml view. This field will be used to show the date and time when the product was created and will be displayed as a read-only field in the form.


  STEP 20.4: Add the Form body of Edit.cshtml.
  STEP 20.5: Add the form submission logic in the Edit action method of the ProductsController class to handle the form submission and update the existing product in the database.
        STEP 20.5.1: Edit [HttpPost] method for 'Edit' at ProductsController.
        STEP 20.5.2: Add validation logic to check if the model state is valid. If not, return the view with the validation errors.
        STEP 20.5.3: If the model state is valid, retrieve the existing Product entity from the database using its ID.
        STEP 20.5.4: Update its properties with the values from the ProductDTO object.
        STEP 20.5.5: If a new image file is uploaded, save it to the server and update the ImageFileName property of the Product entity.
        STEP 20.5.6: Save changes to the database using ApplicationDBContext and call SaveChanges() to persist the changes.
